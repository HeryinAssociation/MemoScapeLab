# 修改日志：Adaptive Pannellum

## 渲染基础

- 保留 Pannellum 的完整球面 `sphere360` 和有限球面 `partialSphere` 渲染。
- 新增独立 WebGL 自适应渲染器，支持弧形照片 `curvedPhoto` 与平面照片 `flatPhoto`。
- 扩展场景类型、运行时校验和渲染路由，覆盖水平/垂直曲率、覆盖角、视觉中心、地平线、边缘压缩、边缘渐隐和视角边界。
- 修复 `curvedPhoto` HTML 图片纹理上下颠倒问题：上传 WebGL 纹理时不再执行错误的纵向翻转，并加入回归测试。

## 可视化调参器

- 构建照片驱动的实时投影调参工作台，支持鼠标、触摸、键盘、缩放和全屏。
- 提供四种投影方式切换、7 组预设、设备尺寸预览、辅助线、实时参数读数、JSON 导入/导出和配置复制。
- 支持照片上传、历史原图查看、投影覆盖、曲率混合、构图校正、Yaw/Pitch/HFOV 边界和边缘模式调整。
- 将嵌入式调参器由暗色界面改为与项目页一致的黄白设计图纸风格。
- 压缩工作台顶部项目栏和四步流程栏，移除调参器重复标题栏，把保存和发布预览入口合并到工作台顶部。

## 项目数据库与素材存储

- 在 Cloudflare Worker 内加入项目 API；使用 D1 保存项目元数据、完整 `scene_json`、工作流步骤和发布状态。
- 使用 R2 保存上传的历史原图、宽幅照片和全景素材；客户端不再把临时 `blob:` URL 当作持久化地址。
- 保存标题、时间、地点、文字备注、原图地址、AIGC 全景地址、投影模式及全部视角/曲率参数。
- 添加 D1 建表语句与 Drizzle SQL 迁移快照；本地开发由 Miniflare 持久化状态。
- 建立项目类型与模式中文标签，保持项目卡片、工作台和 Viewer 使用同一数据模型。

## 项目管理页面 `/proj`

- 新增左侧 AppBar：项目、工作台可用；主页与关于保留占位。
- 使用卡片展示所有照片项目，一张照片对应一个项目。
- 卡片展示全景封面、投影方式、时间、地点、备注、原图/AIGC 素材状态、工作流进度和更新时间。
- 点击项目卡片进入 `/work?id=项目ID`，从数据库恢复该项目并继续编辑。
- 首次本地数据库初始化会创建示例项目；后续实时源码已扩展为导入真实历史照片元数据。

## 四步工作台 `/work`

1. 上传历史原图或已有宽幅/全景照片，并填写元数据。
2. 预留 AI 全景生成步骤；实际模型 API 尚未在本阶段实现。
3. 嵌入现有投影调参器，将保存动作写入项目数据库。
4. 嵌入数据库驱动的发布预览；面向前端的真实发布按钮保持禁用。

## Viewer 与发布预览

- 重构 `/viewer?id=项目ID`，不再读取旧的静态示例 JSON，而是读取项目 API 返回的最新场景参数。
- 移除 Viewer 左侧场景切换栏，改为单项目沉浸预览。
- 进入工作台发布预览前先保存当前场景，再让 Viewer 读取同一项目，避免参数不同步。
- Viewer 可显示数据库中的投影方式、覆盖范围、HFOV、Yaw 边界、时间、地点和备注。
- 将 Viewer 顶栏、状态、参数浮层和右侧发布面板统一为黄白设计图纸风格；照片画布保留深色底以保证对比度。
- 真实“发布到前端”动作仍然禁用，仅提供发布效果预览。
